El producto

Todo lo esencial para administrar un pequeño negocio.

WSoft Lite fue pensado para centralizar las operaciones comerciales más importantes en una aplicación sencilla, práctica y fácil de utilizar.

Una herramienta, múltiples operaciones.

Desde registrar una compra hasta consultar el movimiento de un producto o generar un reporte.

  • Gestión de productos y existencias
  • Ventas mediante punto de venta
  • Compras y movimientos de inventario
  • Clientes, proveedores y vendedores
  • Kardex y reportes
  • Copias de seguridad y restauración

Un proyecto construido para resolver necesidades reales.

WSoft Lite nace con el objetivo de ofrecer una herramienta práctica de gestión comercial para pequeños negocios y emprendimientos.

WSoft Lite 1.6 integra operaciones de ventas, compras, inventario, clientes, proveedores y generación de reportes.
